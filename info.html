About

PetroCAL is developed by Ben Renegar located in VIC.

Ben is a licensed NMI verifier and has checked, calibrated and verified hundreds of thousands of hoses across Australia.

  • Release date: 4/05/2026
  • App build version: b76d31f
  • Data schema version: 3

Requirements

The app has been designed to work on desktop, laptop, tablet and smartphone, however the recommended usage is a tablet in landscape mode.

PetroCAL requires a modern web browser, specifically one of the following:

  • Google Chrome version 88 or newer
  • Microsoft Edge version 88 or newer
  • Mozilla Firefox version 89 or newer

Security and Privacy

PetroCAL is a client-side in-browser application. No data is stored by PetroCAL within the app, or with any other third-parties. No database is used. Data is temporarily stored in local browser storage for easy resume. That data will be lost if the temporary/offline files are cleared within the browser, or not stored at all if local storage is disabled/unsupported.

Generation of the Form 6 spreadsheet occurs within the browser with the results downloaded immediately.

The file-based design of PetroCAL places data management in your hands, allowing you to flexibly manage data files however best suits you and your organisation.

There is no user accounts/profiles or authentication requirements, and no cookies are set or stored to identify individual users.
