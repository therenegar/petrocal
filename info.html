Requirements

PetroCAL requires a modern web browser, specifically:

  • Google Chrome version 88 or newer
  • Microsoft Edge version 88 or newer
  • Mozilla Firefox version 89 or newer

These minimums are based on core features used by the app, including modern JavaScript syntax (for example optional chaining), DOM APIs (for example replaceChildren), and modern CSS layout capabilities (for example aspect-ratio).
