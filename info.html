Requirements

PetroCAL requires a modern web browser, specifically:

  • Google Chrome version 88 or newer
  • Microsoft Edge version 88 or newer
  • Mozilla Firefox version 89 or newer

Security and Privacy

PetroCAL is a client-side in-browser application. No data is stored by PetroCAL within the app, or with any other third-parties. No database is used. Data is temporarily stored (securely) in local browser storage for easy resume. That data will be lost if the temporary/offline files are cleared within the browser, or not stored at all if local storage is disabled/unsupported.

When using export tools such as generating PDF, Excel or Word documents, the dataset is transmitted to a PetroCAL server tool for processing and generating the required output. The data is not kept or stored and is used only to generate the required output. The data is not encrypted during transmission.

Output files are also not stored and are only available for immediate download.

The file-based design of PetroCAL places data management in the hands of the user, allowing you to flexibly manage data files however best suits you and your organisation.

There is no user accounts/profiles or authentication requirements, and no cookies are set or stored to identify individual users.
