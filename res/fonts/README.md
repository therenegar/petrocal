# Local webfont files

Place the following webfont files in this directory:

## DM Sans
- dm-sans-v14-latin-regular.woff2 (weight 400)
- dm-sans-v14-latin-500.woff2 (weight 500)
- dm-sans-v14-latin-700.woff2 (weight 700)
- dm-sans-v14-latin-800.woff2 (weight 800)

## JetBrains Mono
- jetbrains-mono-v23-latin-regular.woff2 (weight 400)
- jetbrains-mono-v23-latin-600.woff2 (weight 600)
- jetbrains-mono-v23-latin-700.woff2 (weight 700)

These are referenced by `css/styles.css` via `@font-face`.
